# Catalyst Agent Demonstration Package

This package runs the safe local demonstration mode with Docker Desktop.
It includes the frontend, FastAPI backend, Kimi K3 configuration template, and
the completed `external-c-dft-20260725-145226` task data.

Remote SSH writes and Slurm submission are disabled by design.

See `docs/DOCKER_DEMO_BEGINNER_GUIDE.md` for the complete instructions.
